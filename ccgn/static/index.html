CCGN · EDGE IOT SECURITY ON oneM2M + ETSI MEC

IoT Anomaly Detection at the Edge

A detector application on the edge host watches a real oneM2M CSE, finds misbehaving devices and blocks them with oneM2M access control.

Connecting…
ProblemIoT devices are too small to protect themselves. Sending all traffic to the cloud for analysis is slow and moves raw data off-site.
What runs hereSimulated sensors talk oneM2M to a real oneM2M CSE on this edge host. A detector AE analyses requests and sensor data with rules and an Isolation Forest and answers through oneM2M ACPs. Services are registered and discovered through ETSI MEC011.
How to read this screenThe diagram lights up the path each request, notification, alert and access-control change actually takes. The panels below the diagram show values read live from the CSE and the MEC registry.
